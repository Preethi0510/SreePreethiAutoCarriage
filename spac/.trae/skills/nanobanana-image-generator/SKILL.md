# Nanobanana Image Generator

This skill generates professional images using nanobanana AI for website sections.

## Usage

1. **Hero Section**: Generate hero background images
2. **About Section**: Create mechanic shop owner photos or workshop images
3. **Services Section**: Generate service-specific images (engine diagnostics, ECM programming, etc.)
4. **Contact Section**: Create location/map-style images

## Image Generation Guidelines

- **Style**: Professional, automotive, modern
- **Quality**: High-resolution, suitable for web
- **Relevance**: Match the specific section content
- **Branding**: Consistent with Sree Preethi Auto Carriage theme

## Section-Specific Requirements

### Hero Section
- Automotive workshop or service bay
- Modern, clean aesthetic
- Warm lighting
- Professional tools/equipment visible

### About Section  
- Mechanic shop owner portrait
- Professional workshop setting
- Trustworthy, experienced appearance
- Indian ethnicity (if generating person)

### Services Section
- Engine diagnostics: Computer/scanning equipment
- ECM programming: Technical/computer imagery
- Immobilizer keys: Key programming tools
- General service: Car maintenance scenes

### Contact Section
- Location imagery
- Workshop exterior
- Professional signage
- Pollachi/Tamil Nadu setting
